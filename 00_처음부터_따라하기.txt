아울북 도서 모니터링 대시보드 — 처음부터 따라하기
====================================================

이 폴더에는 필요한 파일이 전부 들어 있습니다.
특히 자동수집에 필요한 .github 폴더가 들어 있습니다.

[1] GitHub에서 새 저장소 만들기
- 오른쪽 위 + → New repository
- Repository name: book (원하는 이름도 가능)
- Public 선택
- Create repository

[2] 이 ZIP 압축 풀기
압축을 풀면 book-dashboard-v2 폴더가 생깁니다.
그 폴더 '안'에 아래 항목이 있어야 합니다.

.github
 data
 .nojekyll
 index.html
 collect.py
 books.json
 README.md
 00_처음부터_따라하기.txt

중요: .github 폴더가 반드시 있어야 자동수집이 됩니다.

[3] GitHub에 파일 올리기
새 저장소의 빈 화면에서 "uploading an existing file"을 누릅니다.
book-dashboard-v2 폴더 안의 내용 전체를 업로드합니다.
업로드 목록에 .github/workflows/collect.yml이 포함됐는지 꼭 확인합니다.
그다음 Commit changes를 누릅니다.

[4] 사이트 켜기
저장소 → Settings → Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)
Save

잠시 기다리면 Visit site 버튼이 생깁니다.

[5] 처음 데이터 수집하기
저장소 → Actions
왼쪽에 "collect-book-data"가 보이면 클릭
오른쪽 Run workflow → 초록색 Run workflow

실행 결과가 초록색 체크(✓)가 될 때까지 기다립니다.

[6] 데이터 확인하기
저장소 → Code → data → latest.json
{}가 아니라 책 이름/ISBN/서점 데이터가 들어 있으면 수집 성공입니다.
그다음 Pages 사이트를 새로고침합니다.

[7] 이후
GitHub Actions가 매일 오전 7시(한국 시간)에 자동 실행됩니다.

문제가 생기면 가장 먼저 Actions 실행 화면의 빨간 오류 메시지를 캡처해서
ChatGPT에 보내면 됩니다.
